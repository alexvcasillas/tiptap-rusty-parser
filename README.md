# Tiptap Studio

Desktop inspector, structural editor, differ and schema validator for Tiptap / ProseMirror JSON documents, built on a fast Rust parser.

| | |
| --- | --- |
| [`studio/`](studio/) | **Tiptap Studio**, the desktop app (macOS, Windows, Linux). [Download the latest release](https://github.com/alexvcasillas/tiptap-studio/releases). |
| [`parser/`](parser/) | **tiptap-rusty-parser**, the Rust crate behind it: parse, walk, query, mutate, diff and validate documents. [crates.io](https://crates.io/crates/tiptap-rusty-parser), [docs.rs](https://docs.rs/tiptap-rusty-parser). |
| [`bindings/wasm/`](bindings/wasm/) | The same engine for JavaScript via WebAssembly. [npm](https://www.npmjs.com/package/@tiptap-studio/rusty-parser). |

Studio documentation, screenshots and the parser guide are being moved here; until then see [`studio/README.md`](studio/README.md) and [`parser/README.md`](parser/README.md).
