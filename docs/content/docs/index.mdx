This repository ships four things that share one engine:

<Cards>
  <Card title="Tiptap Studio" href="/docs/studio">
    A desktop app to inspect, edit, diff and validate Tiptap / ProseMirror JSON documents.
  </Card>
  <Card title="tiptap-rusty-parser" href="/docs/parser">
    The Rust crate: parse, walk, query, mutate, diff and validate JSONContent.
  </Card>
  <Card title="tiptap-rusty-markdown" href="/docs/markdown">
    Markdown to JSONContent and back (CommonMark and GFM), built on the parser.
  </Card>
  <Card title="@tiptap-studio/rusty-parser" href="/docs/javascript">
    The parser for JavaScript, compiled to WebAssembly.
  </Card>
</Cards>

The API reference for the crates lives on
[docs.rs](https://docs.rs/tiptap-rusty-parser). The [guides](/docs/guides/ai-toolkit) show
how the pieces fit together, starting with the Tiptap AI Toolkit.
