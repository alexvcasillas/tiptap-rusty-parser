This repository ships four things that share one engine:

<Cards>
  <Card title="Tiptap Studio" href="/docs/studio">
    A desktop app to inspect, edit, diff and validate Tiptap / ProseMirror JSON documents.
  </Card>
  <Card title="tiptap-rusty-parser" href="https://docs.rs/tiptap-rusty-parser">
    The Rust crate: parse, walk, query, mutate, diff and validate JSONContent.
  </Card>
  <Card title="tiptap-rusty-markdown" href="https://docs.rs/tiptap-rusty-markdown">
    Markdown to JSONContent and back (CommonMark and GFM), built on the parser.
  </Card>
  <Card title="@tiptap-studio/rusty-parser" href="https://www.npmjs.com/package/@tiptap-studio/rusty-parser">
    The parser for JavaScript, compiled to WebAssembly.
  </Card>
</Cards>

The parser, Markdown and JavaScript guides are moving to this site. Until they land, the
crate documentation on docs.rs and the package READMEs are the reference.
