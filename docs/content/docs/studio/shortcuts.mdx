---
title: Keyboard shortcuts
description: Every shortcut in Tiptap Studio, by where it applies.
---

Some shortcuts work anywhere in the window, others only where the focus is: the tree or
preview, the Diff panes, the find box or the JSON editor. None of the editing keys fire
while you type in a field.

## Anywhere

| Action | macOS | Windows and Linux |
| --- | --- | --- |
| Open a document as A | ⌘O | Ctrl+O |
| Save | ⌘S | Ctrl+S |
| Save as… | ⌘⇧S | Ctrl+Shift+S |
| Undo | ⌘Z | Ctrl+Z |
| Redo | ⌘⇧Z | Ctrl+Shift+Z or Ctrl+Y |
| Delete the selected node (Inspect mode) | ⌫ or Delete | Backspace or Delete |
| Focus the find box | ⌘F | Ctrl+F |
| Next / previous match | ⌘G / ⌘⇧G | Ctrl+G / Ctrl+Shift+G |
| Next / previous schema problem | F8 / ⇧F8 | F8 / Shift+F8 |
| Show or hide the left pane | ⌘1 | Ctrl+1 |
| Show or hide the inspector | ⌘2 | Ctrl+2 |
| Preview or JSON source | ⌘3 | Ctrl+3 |
| Quit | ⌘Q | Ctrl+Q |

## Tree and preview

| Action | macOS | Windows and Linux |
| --- | --- | --- |
| Previous / next node | ↑ / ↓ | ↑ / ↓ |
| Collapse or go to parent | ← | ← |
| Expand or go to first child | → | → |
| First / last node | Home / End | Home / End |
| Clear the selection | Esc | Esc |
| Move the node up / down (Inspect mode) | ⌥↑ / ⌥↓ | Alt+↑ / Alt+↓ |
| Insert an empty paragraph after | ⏎ | Enter |
| Duplicate | ⌘D | Ctrl+D |
| Copy / cut / paste nodes | ⌘C / ⌘X / ⌘V | Ctrl+C / Ctrl+X / Ctrl+V |

## Diff mode

| Action | macOS | Windows and Linux |
| --- | --- | --- |
| Previous / next change | ↑ / ↓ | ↑ / ↓ |
| Take B | ⏎ | Enter |
| Dismiss, or restore a dismissed change | ⌫ | Backspace |

## Find box

| Action | macOS | Windows and Linux |
| --- | --- | --- |
| Next / previous match | ⏎ / ⇧⏎ | Enter / Shift+Enter |
| Clear and return to the tree | Esc | Esc |

## Edit JSON

| Action | macOS | Windows and Linux |
| --- | --- | --- |
| Apply | ⌘⏎ | Ctrl+Enter |
| Cancel | Esc | Esc |
